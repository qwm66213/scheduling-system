# 权限管理功能开发计划

## 一、需求背景

门店有10家（金、凉、国、长、阳、殷、宜、中、灵、柳），需要限制每个门店的店长或该门店可登录后台的人，只能对各自门店的数据做操作和查看，不可对其他门店数据查看及操作。

## 二、数据库现状

**连接信息：** `localhost:3306` / root / root123 / mydb

**已有表：**

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| stores | 门店信息 | id, name, code |
| users | 系统用户 | id, username, password, real_name, store_id, role(admin/manager), is_active |
| employee_profile | 员工档案 | id, name, business_line, position ... |
| revenue_detail | 营业额 | id, revenue_date, meal_period, version, revenue_amount |
| schedule_detail | 排班 | id, schedule_date, employee_name, shift_segment ... |
| attendance_record | 考勤 | id, attendance_date, employee_name, meal_period, actual_status ... |

**默认账号：** admin / admin123（超管，role=admin）

### 3.3 scheduling_rules 表（排班规则，各门店独立）

原有 SQLite 中有此表，需迁移到 MySQL 并加 store_id：

```sql
CREATE TABLE scheduling_rules (
  id INT AUTO_INCREMENT PRIMARY KEY,
  store_id INT NOT NULL COMMENT '所属门店',
  rule_key VARCHAR(100) NOT NULL COMMENT '规则键',
  rule_value TEXT NOT NULL COMMENT '规则值',
  description VARCHAR(200) DEFAULT '' COMMENT '规则描述',
  UNIQUE KEY uk_store_rule (store_id, rule_key),
  FOREIGN KEY (store_id) REFERENCES stores(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

每个门店初始化时插入默认规则（waiter_tables、wok_tables 等）。

### 4.3 middleware/auth.js — JWT 鉴权

```js
const jwt = require('jsonwebtoken');
const JWT_SECRET = 'scheduling-system-secret-2026';

// 登录签发 token
function signToken(user) {
  return jwt.sign(
    { userId: user.id, username: user.username, storeId: user.store_id, role: user.role },
    JWT_SECRET,
    { expiresIn: '7d' }
  );
}

// 中间件：解析 token，注入 req.user
function authMiddleware(req, res, next) {
  const token = req.headers.authorization?.replace('Bearer ', '');
  if (!token) return res.status(401).json({ error: '未登录' });
  try {
    req.user = jwt.verify(token, JWT_SECRET);
    next();
  } catch {
    res.status(401).json({ error: 'token无效或已过期' });
  }
}

// 中间件：仅超管可访问
function adminOnly(req, res, next) {
  if (req.user.role !== 'admin') return res.status(403).json({ error: '无权限' });
  next();
}

// 中间件：自动追加 store_id 过滤条件
function storeFilter(req, res, next) {
  // manager 角色强制过滤自己门店；admin 角色可看所有（或通过 query 指定）
  if (req.user.role === 'manager') {
    req.storeId = req.user.storeId;
  } else {
    req.storeId = req.query.store_id || null; // admin 可选门店
  }
  next();
}
```

### 5.3 api.js 改造

```js
const api = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器：自动带 token
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = 'Bearer ' + token
  return config
})

// 响应拦截器：401 跳转登录
api.interceptors.response.use(
  res => res,
  err => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      localStorage.removeItem('user')
      window.location.href = '/login'
    }
    return Promise.reject(err)
  }
)

// 新增接口
export const login = (data) => api.post('/auth/login', data).then(r => r.data)
export const getStores = () => api.get('/stores').then(r => r.data)
export const getUsers = (params) => api.get('/users', { params }).then(r => r.data)
export const createUser = (data) => api.post('/users', data).then(r => r.data)
export const updateUser = (id, data) => api.put(`/users/${id}`, data).then(r => r.data)
export const deleteUser = (id) => api.delete(`/users/${id}`).then(r => r.data)
```

  const token = localStorage.getItem('token')

  next()
})

## 七、注意事项

- 密码使用 bcryptjs 哈希，不明文存储
- JWT_SECRET 生产环境应改为随机强密钥
- 店长登录后所有数据请求自动限定 store_id，前端无需也无法绕过
- 超管切换门店视角时，前端请求带 `?store_id=xx` 参数
- 删除用户建议软删除（is_active=0），保留审计记录
- 原有 SQLite 相关代码（server/data/）全部清除
